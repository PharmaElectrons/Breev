# Requirements Register

Status vocabulary: **Confirmed** means supported by the governing baseline or a later client clarification; **Pending decision** means implementation is blocked on a named Phase 0 decision; **Deferred/Excluded** records a scope boundary. Source codes are defined in `docs/context/SOURCE_INVENTORY.md`.
